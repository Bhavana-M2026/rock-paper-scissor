# Rock Paper Scissors Game 🎮

A simple Rock-Paper-Scissors game developed using HTML, CSS, and JavaScript.

## 📌 About the Project

This is a web-based Rock-Paper-Scissors game where the user plays against the computer.

The computer randomly selects Rock, Paper, or Scissors, and the game determines the winner.

## ✨ Features

- User can choose Rock, Paper, or Scissors
- Computer makes a random choice
- Displays the winner
- Shows the game result
- Simple and user-friendly interface
- Responsive design

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
